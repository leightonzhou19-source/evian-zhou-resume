# Evian Zhou · Resume

Static personal resume site. The repository root is the GitHub Pages publishing directory.

## Publish

In repository Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**. GitHub Pages will publish the site at `https://leightonzhou19-source.github.io/evian-zhou-resume/` when the repository name is `evian-zhou-resume`.

## Update

Edit `index.html`, `style.css`, `script.js`, `i18n.js`, or the files in `assets/`, then push the changes to `main`. The site uses relative asset paths and requires no build step.
